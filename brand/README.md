# YSG Audio Labs — 브랜드

## 마크: Split Node

중심에서 세 방향으로 뻗으며 끝으로 갈수록 얇아지는 획.

- **Y 스플리터** — 한 소스가 갈라지는 오디오의 실제 개념. 동시에 YSG 의 Y
- **얇아지는 굵기** — 거리에 따른 감쇠(attenuation)
- **좁은 평평 마감** — 계측기의 마감. 세 획이 만나는 중심이 소스
- 파형도 헤드폰도 쓰지 않는다. 획 3개뿐이라 16px 에서도 형태가 남는다

툴 다섯 개(SoundField · Spatial Renderer · Attenuation/Bus Routing/Stereo Auditor)의
공통점은 **보이지 않는 소리 공간을 분해해서 검증한다**는 것이다. 그걸 기하로 옮겼다.

## 파일

생성기 하나가 전부 만든다. **좌표를 손으로 고치지 말 것.**

```bash
python brand/build_brand.py   # SVG · TSX 8종
python brand/build_ico.py     # 파비콘 ICO/PNG (PIL 로 기하 직접 래스터라이즈)
```

`build_ico.py` 는 SVG 를 변환하지 않고 **같은 수식으로 직접 그린다** — 이 PC 에
SVG 렌더러가 없고, 폴리곤 3개라 직접 그리는 편이 더 정확하다. 목표 크기의 8배로
그린 뒤 LANCZOS 로 줄여 16px 에서도 획 끝이 남는다 (실측: 16px 안 마크 화소 18%).

| 파일 | 용도 |
|---|---|
| `ysg-mark-mono.svg` | 흑백 마크 — 앱 타이틀바 (currentColor) |

## 확정 파라미터

```
reach=9.9  w0=5.2  w1=1.2  spread=60°  soften=0.45   node_y=9.785
```

reach 는 세 획 **공통** 길이다. 끝 마감은 좌우 대칭 평평 (bevel 없음).

`node_y` 는 세 획이 만나는 원점의 세로 위치로, **칸 중심 12 가 아니다.** 아래 획만
곧게 내려가고 위 두 획은 60° 로 누워 있어서 원점을 12 에 두면 잉크가 아래로
`+2.215` 쏠린다 (26px 렌더에서 2.4px). 잉크의 위아래 끝 중간이 12 가 되도록 원점을
그만큼 올린 값이며, 생성기가 `reach·w1·spread` 에서 계산한다 — 손으로 박지 말 것.

## 웹 배지는 컬러 풀버전을 쓴다 (2026-09-09)

허브 6페이지의 상단 배지는 `assets/ysg-mark-color.svg` 를 `<img>` 로 넣는다.
원래는 단색(`ysg-mark-web.svg`)을 인라인했는데, 사용자가 **"간략한 버전 말고 실제
풀버전"** 을 요구했다. 20px 에서는 그라디언트가 뭉치므로 **24px**(좁은 화면 22px)로
키워서 넣는다.

바뀐 점 두 가지를 알아 둘 것:

- **페이지별 시안색을 따르지 않는다.** 단색일 때는 `currentColor` 로 각 페이지의
  `--wave` 를 따라갔지만, 컬러 마크는 색이 박혀 있어 6페이지가 같은 브랜드 색이 된다.
  브랜드 마크로는 이게 맞다 — 제품색은 각 툴의 제품 마크가 담당한다
- **알약 높이를 고정했다.** 배지·언어토글·GitHub 버튼·칩이 30px(좁은 화면 28px)로
  통일돼 있다. 마크 크기를 바꾸면 배지만 커져 다시 들쭉날쭉해진다

## 하지 말 것

- **기울이기** — 3중 대칭이 무너지고 Y 가 안 읽힌다
- **획 굵기 균일하게** — 감쇠가 의미다. 균일하면 그냥 Y 글자
- **끝을 둥글리기** — 위 두 획이 '뿔' 처럼 보인다 (검토에서 기각한 형태)
- **세 획 길이를 다르게** — Y 로 읽히게 하려고 아래 획만 늘렸다가 "대충 봐도 비대칭" 지적을 받았다 (2026-09-09). 위 두 획이 벌어진 배치만으로 이미 Y 다. 길이는 반드시 같게 둔다
- **끝을 한쪽만 사선으로 깎기** — 세 획이 모두 같은 방향으로 기울어 마크 전체가 돌아간 것처럼 보인다. 끝 마감은 좌우 대칭이어야 한다
- **노드 원점을 칸 중심(12)으로 되돌리기** — 세 획이 120° 대칭이어도 잉크는 아래로
  쏠린다. 타이틀바에서 "글자와 세로 중앙이 안 맞는다" 는 지적을 받은 원인이며,
  정렬 CSS 로 땜빵하면 파비콘·웹 배지는 그대로 삐뚤어져 있다
- **세로 정렬을 CSS 로 밀어서 맞추기** — 마크가 쓰이는 자리가 열 군데다.
  기하를 고쳐야 전부 한 번에 맞는다
- **흑백 마크에 색 박기** — currentColor 를 쓰는 이유는 세 테마 대응이다
- **웹 배지 알약 높이를 마크 크기에 맡기기** — `min-height` 로 두면 마크가 커질 때 배지만 자라 옆의 언어토글·GitHub 버튼과 어긋난다. 실측으로 30/28/30 이 섞여 있던 걸 잡았다 (2026-09-09). 높이는 고정한다
- **감쇠 끝 색을 `Far Deep` 까지 내리기** — 배경 잉크와 붙어 획이 사라진다.
  `Depth Indigo` 까지만 내리고, 윤곽선은 시안 고정으로 형태를 남긴다

## 모션을 넣을 때

`<img src="ysg-mark-motion.svg">` 로 넣어도 재생된다. 다만 **애니메이션의 모든
keyframes 는 0% 가 완성 상태**여야 한다 — 애니메이션이 등록된 뒤 렌더가 진행되지
않는 환경(창이 가려짐, 썸네일 캡처, 정적 렌더러)에서는 첫 프레임에 멈추기 때문이다.
시작 상태를 0% 에 두면 그 환경에서 **로고가 아예 사라진다.** 실제로 그렇게 만들어
두 번 빈 화면을 봤다. 이 구조를 뒤집지 말 것.

## 기각한 시안

같은 길을 다시 걷지 않기 위해 이유를 남긴다. 시안 스크립트(`explore*.py`)와
진행 메모는 저장소에 올리지 않고 작업 PC 에만 둔다 — 로컬 경로가 박혀 있어서다.
여기 표가 그 요약이다.

| 시안 | 기각 이유 |
|---|---|
| 아이소메트릭 큐브 (1차) | 갭·라운딩·비대칭을 다 흔들어도 흔한 3D 큐브. 블록체인/데이터 로고와 구분 안 됨 |
| 조리개 블레이드 (2차) | 26px 에서 형태 붕괴 |
| 쐐기 비틀기 (3·4차) | 회전감을 얻고 **Y 를 잃었다** — 갈고리·새 발자국으로 읽힘 |
| 삼각 코어 + 중심 공백 (5차) | 세 조각이 흩어져 보여 Y 가 성립하지 않음. **Y 는 획이 중심에서 만나야 Y 다** |
| 둥근 끝 마감 (6차) | 위 두 획이 뿔처럼 보임 |
| 중심 원형 노드 (6차) | 획과 합쳐져 안 보임 — 무의미 |
| 아래 획만 길게 + 한쪽 사선 (7차) | 3중 대칭이 깨져 비대칭으로 보였다. 8차에서 길이 통일 + 좌우 대칭 마감으로 교정 |
